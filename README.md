# Torrent Disk для macOS

Открывает торренты как диски в Finder, не скачивая их целиком. Перетащите `.torrent`-файл в окно
программы, и раздача появится отдельным диском в боковой панели Finder. ZIP-архивы внутри
показываются как обычные папки: если открыть одну книгу из архива на несколько гигабайт,
скачаются только оглавление архива и куски с этой книгой.

Внутри работает собственный торрент-движок (`engine/`, Go, на библиотеке
[anacrolix/torrent](https://github.com/anacrolix/torrent)). Структура раздачи видна сразу,
по данным .torrent-файла; данные скачиваются, только когда вы открываете файл или заходите
в архив. Движок отдаёт раздачи по WebDAV, а Torrent Disk подключает их как сетевые диски.
Расширение ядра macFUSE не нужно.

## Установка

Требуется macOS 13 или новее на Mac с Apple Silicon (M1 и новее).

1. Скачайте **TorrentDisk.dmg** со страницы [Releases](https://github.com/Arthuralend/TorrentDisk/releases/latest).
2. Откройте его и перетащите **Torrent Disk** в папку «Программы».
3. При первом запуске macOS сообщит, что не может проверить разработчика: у приложения нет платной
   подписи Apple. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите
   «Всё равно открыть». Это нужно сделать только один раз.

   Можно и через Терминал: `xattr -dr com.apple.quarantine "/Applications/Torrent Disk.app"`.
4. Если macOS спросит, разрешить ли Torrent Disk доступ к локальной сети, нажмите «Разрешить».

## Использование

- **Добавить торрент:** перетащите `.torrent` в окно программы или на её значок в Dock, нажмите
  «Выбрать файл…» (⌘O) или выберите в Finder «Открыть в программе → Torrent Disk». Торрент сразу
  подключится и откроется в Finder.
- **Недавние торренты:** все добавленные торренты остаются в списке. У каждого есть кнопки
  «Подключить», «Открыть» и «Отключить». Каждый торрент подключается отдельным диском со своим именем.
- **Удалить из истории:** правый клик по торренту → «Удалить из истории».
- При выходе из программы все диски отключаются.

Данные хранятся в `~/Library/Application Support/TorrentDisk`. Скачанные куски занимают не больше 2 ГБ,
старые удаляются автоматически.

## Ограничения

- Как папки открываются только ZIP-архивы. RAR и 7z видны как обычные файлы: их можно
  скопировать, но для этого скачается весь архив.
- Finder заранее читает файлы, чтобы строить превью. Если он начинает качать лишнее, используйте
  для этого диска ForkLift или Cyberduck.
- Если у раздачи нет живых раздающих, файл не откроется: Finder подождёт до 3 минут и покажет
  ошибку. Число пиров видно в окне программы.

## Сборка

Приложение написано на SwiftUI (`app/Sources`), движок — на Go (`engine/`). DMG собирает
GitHub Actions на macOS (`.github/workflows/build.yml`). При каждой сборке запускаются тесты
движка (раздача с ZIP-архивом скачивается от тестового пира, проверяется, что для одной книги
скачивается лишь малая часть) и проверка, что торрент подключается как диск.
Чтобы выпустить релиз, откройте **Actions → build → Run workflow** и укажите версию.
Локально на Mac с Xcode: `bash build.sh`, результат появится в `build/TorrentDisk.dmg`.

## Удаление

Закройте программу, затем:

```bash
rm -rf "/Applications/Torrent Disk.app" ~/Library/Application\ Support/TorrentDisk
```
